# Tarea: Mi prompt profesional
Laboratorio 06: Fundamentos de Ingenieria de Prompts.
 
## Funcionalidad elegida


CRUD de productos para una tienda virtual

La funcionalidad permitirá:

- Registrar productos.
- Listar productos.
- Actualizar información de productos.
- Eliminar productos.
- Almacenar los datos en memoria usando arreglos.
- Trabajar con Java sin utilizar bases de datos ni librerías externas.
 
## Version 1: prompt basico

```
Crea un programa en Java para administrar productos.
```
 **¿Qué cambié?**

Esta es la versión inicial, con una descripción muy general.

**¿Por qué?**

Quería obtener una primera respuesta rápida sobre la funcionalidad.

**¿Qué mejoró en la respuesta?**

La IA generó un programa relacionado con productos, pero:

No especificó las operaciones necesarias.
No indicó estructura de clases.
No definió restricciones.
La respuesta fue demasiado genérica.
## Version 2

```
Actúa como desarrollador Java. Crea un programa de consola para administrar productos. Debe permitir agregar, listar, actualizar y eliminar productos. Utiliza Programación Orientada a Objetos.
```
 **¿Qué cambié?**

Añadí un rol específico ("desarrollador Java").
Definí claramente las operaciones CRUD.
Solicité el uso de POO.

**¿Por qué?**

Para obtener una solución más alineada con lo que realmente necesitaba.

**¿Qué mejoró en la respuesta?**

Se generaron clases más organizadas.
Aparecieron métodos CRUD.
La solución fue más cercana a un proyecto real.

Sin embargo:

No se especificó el formato de salida.
No existían restricciones.
No había ejemplos del resultado esperado.

## Version 3: prompt final

```
Eres un desarrollador Java senior especializado en Programación Orientada a Objetos. Genera un programa completo en Java que implemente un CRUD de productos para una tienda virtual. El programa será utilizado por estudiantes que están aprendiendo estructuras de datos y POO. Debe ejecutarse en consola y permitir registrar, listar, editar y eliminar productos. Explica brevemente la solución, muestra el diagrama de clases en texto, presenta el código completo, incluye comentarios en las partes importantes, agrega un ejemplo de ejecución. Usa esta estructura por producto: Producto: ID: 1, Nombre: Laptop, Precio: 3500.00. No uses librerías externas ni bases de datos. Utiliza únicamente Java estándar y almacenamiento en memoria mediante ArrayList.
```
 
**¿Qué cambié?**

Se agregó un rol profesional.
Se definió claramente la tarea.
Se proporcionó contexto de uso.
Se añadieron ejemplos.
Se definió el formato esperado.
Se incluyó una restricción técnica.

**¿Por qué?**

Porque los prompts detallados reducen ambigüedades y producen respuestas más precisas.

**¿Qué mejoró en la respuesta?**

Código más organizado.
Mayor calidad técnica.
Explicaciones más completas.
Cumplimiento de requisitos académicos.
Salida estructurada y fácil de evaluar.
